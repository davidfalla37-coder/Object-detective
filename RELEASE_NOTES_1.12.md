# Object Detective 1.12 — candidate release

## Changes
- Corrected the photo control so it allows all five photos shown in the interface.
- Added a skippable first-use guide with a replay option in App settings.
- Added System, Light and Dark appearance choices, saved on the device.
- Separated broad object-type confidence from exact make/model certainty in results.
- Added optional correction and general feedback sharing. Nothing is sent automatically, and photos are not attached.
- Added a Google Play listing link in App settings.
- Updated the store description and prepared a screenshot capture plan.

## Review notes
- The app’s AI identification and value estimates can still be wrong.
- Accuracy feedback is shared only if the user chooses a share destination.
- This app build uses the existing analysis service. No live backend configuration was changed.
- Capture Play Store screenshots from the signed candidate on a real device before updating the listing.
