# Object Detective Play Store screenshot plan

Capture these from the signed 1.12 release on a real Android device. Keep the visible app UI genuine; use short captions outside the phone screenshots only if the Play Console format allows them.

1. **Investigate an object** — show the first-photo screen and “0 of 5 photos” guidance.
2. **Add useful angles** — show a whole-object photo, a label close-up and the five-photo counter.
3. **See what is supported** — show a result with object-type confidence and exact model certainty visible separately.
4. **Check the evidence** — show the result explanation and verification advice.
5. **Follow through** — show saved investigations, follow-up chat or the editable sale-listing draft.

Before uploading, remove personal photos, account details, notifications and unrelated app chrome from the captured screens. Do not use a simulated result or claim an exact identification unless the displayed result supports it.
