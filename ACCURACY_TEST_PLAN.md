# Accuracy test plan

Use this sheet to compare the current app with a future candidate build. Use the same item photographs and reference information each time. Record what the app says before looking up the answer.

## Test cases

| Case | Item and photos | Independent reference |
| --- | --- | --- |
| Watch strap | One full view, connector close-up, watch back or model label | Watch maker's model/fit guide; measure strap width |
| Used everyday item | Clear photos showing all sides and wear | Exact model/label plus at least three comparable UK completed-and-sold listings |
| Branded tool or electronic | Overall view and readable brand/model label | Manufacturer page or manual |
| Car part with number | Overall view and readable OEM/part number | Manufacturer catalogue or trusted parts catalogue for the exact vehicle |
| Motorcycle part | Overall view, connector/mount and any part number | Manufacturer or trusted parts catalogue for the exact bike |
| Unlabelled component | Overall view and close-up of distinctive details | Independent knowledgeable source; record when identity cannot be confirmed |
| Poor photo | One deliberately dark or blurry image | Expected behaviour: ask for a clearer photo or show uncertainty |
| Multi-angle | Repeat a case with one photo, then with up to three views | Check whether the added views correct or narrow the result |

## Record each run

- App version and date
- Case and photo count
- Likely object, brand/model and category
- Identification confidence and explanation
- Condition and second-hand value range
- Any fitment or safety claim
- What the independent reference confirms
- For value checks: links, sold prices, condition and postage for comparable items
- Result: correct, partly correct, incorrect, or unable to verify
- What would have made the answer safer or more useful

## Review rules

- Confirm identity using a label, manual or reliable catalogue where possible; do not treat the app's own answer as its reference.
- Compare prices only with the same model or a close equivalent in similar condition. Prefer completed and sold listings over current asking prices. Record postage and missing parts.
- If there are fewer than three credible sold comparisons, mark the value as “not enough reference data” instead of calling it accurate or inaccurate.
- Mark unsupported exact model, compatibility or safety claims as failures even when the broad object category is right.
- Treat identification confidence as confidence in visual identification only; it does not establish condition, value or fit.
- Re-run the same cases after a change. Keep both sets of notes so improvements and regressions are visible.
